Usage

Before using voice input, you must import at least one speech recognition model.

To import a model:

  1. Open the application's main menu.
  2. Select "Import".
  3. Choose a ZIP archive containing at least one model.

After the import is complete, select the desired model from the list.

The application requires permission to access the microphone in order to function.

Adding Your Own Models

To create your own model package, you will need:

  1. A Microsoft Azure Embedded Speech model.
  2. A license or license key for that model.

Create a file named license.txt in the model directory, then compress the entire folder into a ZIP archive and import it through the application.
