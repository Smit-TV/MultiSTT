MultiSTT Help

User guide for MultiSTT — Multilingual Voice Input.

This guide explains the main features of the application, how to use voice input, and how to add custom speech recognition models.

1. Getting Started

Before using voice input, you must import at least one speech recognition model.

The application also requires permission to access your microphone. Without this permission, audio recording and speech recognition will not be available.

2. Importing Models

Follow these steps to import a model:

  1. Open the application's navigation menu.
  2. Select "Import Speech Recognition Model".
  3. Select a ZIP archive containing speech recognition models.
  4. Wait for the extraction and import process to finish.

After a successful import, the models will appear in the list. Select the desired model to use it for speech recognition.

Note: A single ZIP archive can contain multiple models and recognition engines.

3. Using Voice Input

Once you have imported a model and granted the required permissions, you can start using voice input.

Single Recognition

Tap the voice input button, speak the desired text, and wait for recognition to finish.

Continuous Recognition

To enable continuous recognition, press and hold the voice input button. The application will continue recognizing speech until you stop the recognition process.

Switching Recognition Languages

Use the following commands to switch between recognition languages:

  • Next Recognition Language.
  • Previous Recognition Language.

4. Adding Custom Microsoft Models

MultiSTT allows you to add your own Microsoft Azure Embedded Speech models.

Requirements

To add a model, you will need:

  1. Microsoft Azure Embedded Speech model files.
  2. A corresponding license or license key.

Model File Location

Place your model files in the following directory:

/storage/emulated/0/Android/data/com.github.smittv.multistt/files/microsoft

Adding a Model to the Application

  1. Open the application's navigation menu.
  2. Navigate to the "Recognition Engines" section.
  3. Find the Microsoft Offline engine.
  4. Tap the "Add" button next to it.
  5. Fill in the required fields in the dialog:
    • Name: A custom name for the model.
    • Folder: The name of the directory containing the model files.
    • Locale: The model's language and region, for example en-US or ru-RU.
    • Parameters: The license key or other parameters required to use the model.
  6. Confirm the model registration.

After successful registration, the model will appear in the list of available models and will be ready to use.
