Использование

Перед использованием голосового ввода необходимо импортировать как минимум одну модель распознавания речи.

Для импорта модели выполните следующие действия:

  1. Откройте главное меню приложения.
  2. Выберите пункт «Импортировать».
  3. Укажите ZIP-архив, содержащий хотя бы одну модель.

После завершения импорта выберите нужную модель из списка.

Для работы приложения необходимо предоставить разрешение на использование микрофона.

Добавление собственных моделей

Для создания собственного пакета модели необходимы:

  1. Модель Microsoft Azure Embedded Speech.
  2. Лицензия или лицензионный ключ для данной модели.

Создайте файл license.txt в каталоге модели, затем заархивируйте всю папку в ZIP-архив и импортируйте его через приложение.

⚠ Предупреждение

Приложение предоставляется «как есть», без каких-либо гарантий. Используйте его только в законных и мирных целях.

При использовании моделей Microsoft Azure Embedded Speech обязательно соблюдайте условия их лицензии.
