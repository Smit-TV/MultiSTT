Справка MultiSTT

Руководство пользователя приложения MultiSTT — многоязычного голосового ввода.

В этом руководстве описаны основные возможности приложения, порядок использования голосового ввода и способы добавления собственных моделей распознавания речи.

Содержание

  1. Начало работы
  2. Импорт моделей
  3. Использование голосового ввода
  4. Добавление собственных моделей Microsoft
  5. Лицензирование и ограничения

1. Начало работы

Перед использованием голосового ввода необходимо импортировать хотя бы одну модель распознавания речи.

Также приложению требуется разрешение на использование микрофона. Без него запись и распознавание речи будут недоступны.

2. Импорт моделей

Для импорта модели выполните следующие действия:

  1. Откройте главное меню приложения.
  2. Выберите пункт «Импортировать модель».
  3. Укажите ZIP-архив, содержащий модели распознавания речи.
  4. Дождитесь завершения распаковки и импорта.

После успешного импорта модели появятся в списке. Выберите нужную модель, чтобы использовать её для распознавания речи.

Примечание: Один ZIP-архив может содержать несколько моделей и движков распознавания.

3. Использование голосового ввода

После импорта модели и предоставления необходимых разрешений можно использовать голосовой ввод.

Однократное распознавание

Нажмите кнопку голосового ввода, произнесите нужный текст и дождитесь завершения распознавания.

Непрерывное распознавание

Для включения непрерывного распознавания нажмите и удерживайте кнопку голосового ввода. Приложение будет продолжать распознавание речи, пока режим не будет остановлен.

Переключение языков

Для переключения между языками распознавания используйте соответствующие команды:

  • Следующий язык распознавания.
  • Предыдущий язык распознавания.

4. Добавление собственных моделей Microsoft

MultiSTT позволяет добавлять собственные модели Microsoft Azure Embedded Speech.

Необходимые компоненты

Для добавления модели потребуются:

  1. Файлы модели Microsoft Azure Embedded Speech.
  2. Соответствующий лицензионный ключ или лицензия.

Расположение файлов модели

Поместите файлы модели в следующую директорию:

/storage/emulated/0/Android/data/com.github.smittv.multistt/files/microsoft

Добавление модели в приложение

  1. Откройте навигационное меню приложения.
  2. Перейдите в раздел «Движки распознавания».
  3. Найдите движок Microsoft Offline.
  4. Нажмите кнопку «Добавить» напротив него.
  5. В открывшемся окне заполните необходимые поля:
    • Название: произвольное название модели.
    • Папка: название директории, содержащей файлы модели.
    • Локаль: язык и регион модели, например en-US или ru-RU.
    • Параметры: лицензионный ключ или другие параметры, необходимые для работы модели.
  6. Подтвердите добавление модели.

После успешного добавления модель появится в списке доступных моделей и будет готова к использованию.

5. Лицензирование и ограничения

Предупреждение

Приложение предоставляется «как есть», без каких-либо гарантий.

При использовании моделей Microsoft Azure Embedded Speech обязательно соблюдайте условия соответствующей лицензии. Убедитесь, что у вас есть необходимые права на использование файлов моделей и лицензионных ключей.
